## 🚀 25. Databases - Relational Calculus

### 📌 Problem

We execute the following query (in Relational Calculus) on a set of integers **S**.

For the given set **S**, what will be the answer?

```
{ x | ∀ y S(x) ∧ S(y) → y ≤ x }
```

```
S = {4,5,6,7,10,11,19,18,3}
```

---

### 💡 Explanation

The query returns all values **x** in the set **S** such that **every** element `y` in `S` satisfies:

```
y ≤ x
```

In other words, `x` must be **greater than or equal to every element** in the set. Therefore, the query returns the **maximum element** of `S`.

Given:

```
S = {4,5,6,7,10,11,19,18,3}
```

The largest element is:

```
19
```

---

### 💻 Solution

```
19
```
