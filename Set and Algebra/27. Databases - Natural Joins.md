## 🚀 27. Databases - Natural Joins

### 📌 Problem

Relation **R(A, C)** has the following tuples:

| A | C |
|---|---|
| 3 | 3 |
| 16 | 4 |
| 12 | 3 |
| 3 | 15 |
| 27 | 1 |

Relation **S(B, C, D)** has the following tuples:

| B | C | D |
|---|---|---|
| 50 | 1 | 6 |
| 1 | 55 | 8 |
| 4 | 3 | 9 |

The following tuple is in the result of the natural join between **R** and **S**, where tuples are structured as **(A, B, C, D)**:

```
(27, X, Y, Z)
```

Find the values of **X**, **Y**, and **Z**.

---

### 💡 Explanation

A **Natural Join** combines rows from two relations based on their common attribute(s). Here, the common attribute is **C**.

For the tuple with:

```
A = 27
```

From relation **R**:

```
(27, 1)
```

So, `C = 1`.

Looking in relation **S**, the tuple with `C = 1` is:

```
(50, 1, 6)
```

Therefore:

- `B = 50`
- `C = 1`
- `D = 6`

The resulting joined tuple is:

```
(27, 50, 1, 6)
```

---

### 💻 Solution

```text
50
1
6
```
