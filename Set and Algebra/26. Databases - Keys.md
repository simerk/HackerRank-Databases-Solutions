## 🚀 26. Databases - Keys

### 📌 Problem

A database table with three fields **(bookname, author, language)** has been created.

| Book Name | Author | Language |
|-----------|--------|----------|
| A Tale of Two Cities | Charles Dickens | English |
| Oliver Twist | Charles Dickens | English |
| Godaan | Premchand | Hindi |
| Chandrakanta | Devaki Nandan Khatri | Hindi |
| Hamlet | William Shakespeare | English |
| The Merchant of Venice | William Shakespeare | English |

Which of these three fields may be used as the **primary key**?

---

### 💡 Explanation

A **primary key** is a column that uniquely identifies each row in a table. Therefore, its values must be **unique** and **non-null**.

Checking each field:

- **Book Name** → All values are unique. ✅
- **Author** → Authors like *Charles Dickens* and *William Shakespeare* appear more than once. ❌
- **Language** → Both *English* and *Hindi* occur multiple times. ❌

Hence, **Book Name** is the only field that can uniquely identify every record.

---

### 💻 Solution

```text
bookname
```
