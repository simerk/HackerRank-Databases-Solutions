## 🚀 32. Database Normalization #4

### 📌 Problem

A database, normalized as per **Second Normal Form (2NF)** rules, has been split into **10 tables**.

Each of the tables has exactly:

- **1 key attribute**
- **1 non-key attribute**

What is the **minimum number of tables** required to express this database in **Third Normal Form (3NF)**?

---

### 💡 Explanation

A relation is in **Third Normal Form (3NF)** if there are **no transitive dependencies** between non-key attributes.

Since each table contains only:

- **one key attribute**, and
- **one non-key attribute**,

there is **only one non-key attribute** in each table. Therefore, there cannot be any dependency between non-key attributes, and **transitive dependencies are impossible**.

As a result, every table is **already in 3NF**, and no further decomposition is required.

Hence, the minimum number of tables remains **10**.

---

### 💻 Solution

```text
10
```
