## 🚀 33. Database Normalization #5

### 📌 Problem

Consider the following relation and determinants.

```
R(a, b, c, d)

a, c → b, d
a, d → b
```

Also, **(a, b)** is a primary key for the above relation.

The relation is in **xNF**, where **x** may take one of the following values:

- `1` → 1NF
- `2` → 2NF
- `3` → 3NF
- `3.5` → BCNF

What is the **maximum possible value of x** such that the relation satisfies the **xNF** form?

---

### 💡 Explanation

The given functional dependencies are:

```
ac → bd
ad → b
```

and the primary key is:

```
(a, b)
```

To satisfy **BCNF**, every non-trivial functional dependency must have a **superkey** on its left-hand side.

Consider the dependency:

```
ac → bd
```

The determinant `ac` is **not** a superkey because the given primary key is `(a, b)`.

Since a non-superkey determines other attributes, the relation **violates BCNF**.

For **3NF**, a functional dependency is allowed if either:

- the determinant is a superkey, **or**
- the dependent attribute is a **prime attribute** (part of a candidate key).

Here, the dependency:

```
ad → b
```

has a non-superkey determinant, but `b` is a **prime attribute** because it is part of the primary key `(a, b)`.

Thus, the relation satisfies **3NF** but **not BCNF**.

---

### 💻 Solution

```text
3
```
