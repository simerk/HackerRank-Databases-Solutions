## 🚀 35. Database Normalization #7

### 📌 Problem

Consider the following relations and determinants for a simple movie library.

**Relations:**

```
movie(DESCRIPTION, serialno)
serial(SERIALNO, director)
customer(name, addr, MEMBERNO)
borrow(memberno, DATE, SERIALNO)
```

**Determinants:**

```
description → director, serialno
serialno → description
serialno → director
name, addr → memberno
memberno → name, addr
serialno, date → memberno
```

The relation is in **xNF**, where **x** may take one of the following values:

- `1` → 1NF
- `2` → 2NF
- `3` → 3NF
- `3.5` → BCNF

What is the maximum possible value of **x**?

---

### 💡 Explanation

Let's analyze each relation individually.

#### 1. `movie(DESCRIPTION, serialno)`

Functional dependencies:

```
description → serialno
serialno → description
```

Both `DESCRIPTION` and `SERIALNO` uniquely determine each other, making them **candidate keys**. Every determinant is therefore a candidate key, so this relation satisfies **BCNF**.

#### 2. `serial(SERIALNO, director)`

Functional dependency:

```
serialno → director
```

`SERIALNO` is the primary key, so every non-key attribute depends directly on the key. This relation is also in **BCNF**.

#### 3. `customer(name, addr, MEMBERNO)`

Functional dependencies:

```
name, addr → memberno
memberno → name, addr
```

Both `MEMBERNO` and `(name, addr)` are candidate keys. Hence, this relation satisfies **BCNF**.

#### 4. `borrow(memberno, DATE, SERIALNO)`

Functional dependency:

```
serialno, date → memberno
```

The primary key is `(DATE, SERIALNO)`, so the determinant is a superkey. Therefore, this relation also satisfies **BCNF**.

Since **every relation** is in **BCNF**, the entire database satisfies **BCNF**.

---

### 💻 Solution

```text
3.5
```
