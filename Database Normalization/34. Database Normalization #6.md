## 🚀 34. Database Normalization #6

### 📌 Problem

Consider a simple movie library with the following relations and determinants.

**Relations (The key is CAPITALIZED):**

```
customer(name, addr, MEMBERNO)
movie(DESCRIPTION, director, serialno)
borrow(memberno, DATE, SERIALNO)
```

**Determinants:**

```
description → director, serialno
serialno → description
serialno → director
name, addr → memberno
memberno → name, addr
serialno, date → memberno
```

The relation is in **xNF**, where **x** may take one of the following values:

- `1` → 1NF
- `2` → 2NF
- `3` → 3NF
- `3.5` → BCNF

What is the maximum possible value of **x**?

---

### 💡 Explanation

The declared primary keys are:

- `MEMBERNO` for **customer**
- `DESCRIPTION` for **movie**
- `(DATE, SERIALNO)` for **borrow**

Consider the **movie** relation:

```
movie(DESCRIPTION, director, serialno)
```

with the functional dependencies:

```
DESCRIPTION → director, serialno
serialno → description
serialno → director
```

Here, the dependency:

```
serialno → director
```

has a **non-key determinant** (`serialno`) determining a **non-prime attribute** (`director`).

This creates a **transitive dependency** with respect to the declared primary key:

```
DESCRIPTION → serialno → director
```

A transitive dependency violates **Third Normal Form (3NF)**.

Since the primary key consists of a single attribute, there are **no partial dependencies**, so the relation satisfies **Second Normal Form (2NF)**.

Therefore, the highest normal form satisfied is **2NF**.

---

### 💻 Solution

```text
2
```
