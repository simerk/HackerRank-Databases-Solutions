## 🚀 38. Database Normalization #10

### 📌 Problem

The following table stores information about pizza deliveries.

| Restaurant | Crust | Delivery Area |
|------------|--------|---------------|
| X Pizza | Thick | Whitefield |
| X Pizza | Thick | Greenville |
| X Pizza | Thick | Capital |
| X Pizza | Stuffed | Whitefield |
| X Pizza | Stuffed | Greenville |
| X Pizza | Stuffed | Capital |
| Papa Pizza | Thin | Capital |
| Papa Pizza | Stuffed | Capital |
| F1 Pizza | Thick | Whitefield |
| F1 Pizza | Thick | Greenville |
| F1 Pizza | Thin | Whitefield |
| F1 Pizza | Thin | Greenville |

The table is converted into **Fourth Normal Form (4NF)**, resulting in **two tables**, each with **two columns** and **N** rows.

Both new tables contain the **same number of rows**.

Find the value of **N**.

---

### 💡 Explanation

The relation contains two **independent multivalued dependencies**:

- A restaurant can offer **multiple crust types**.
- A restaurant can deliver to **multiple delivery areas**.

To satisfy **Fourth Normal Form (4NF)**, the table is decomposed into:

**Restaurant–Crust**

| Restaurant | Crust |
|------------|--------|
| X Pizza | Thick |
| X Pizza | Stuffed |
| Papa Pizza | Thin |
| Papa Pizza | Stuffed |
| F1 Pizza | Thick |
| F1 Pizza | Thin |

Number of rows = **6**

**Restaurant–Delivery Area**

| Restaurant | Delivery Area |
|------------|---------------|
| X Pizza | Whitefield |
| X Pizza | Greenville |
| X Pizza | Capital |
| Papa Pizza | Capital |
| F1 Pizza | Whitefield |
| F1 Pizza | Greenville |

Number of rows = **6**

Therefore, each decomposed table contains **6** rows.

---

### 💻 Solution

```text
6
```
