## 🚀 10. Database Query Languages

### 📌 Problem

Using which language can a user request information from a database?

- Query
- Structural
- Relational
- Compiler

---

### 💡 Explanation

A **Query Language** is used to request, retrieve, and manipulate data stored in a database.

The most widely used query language is **SQL (Structured Query Language)**, which allows users to perform operations such as querying, inserting, updating, and deleting data.

---

### 💻 Solution

```
Query
```
