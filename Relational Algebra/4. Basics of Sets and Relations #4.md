## 🚀 4. Basics of Sets and Relations #4

### 📌 Problem

You are given two sets.

```
Set A = {1,2,3,4,5,6}
Set B = {2,3,4,5,6,7,8}
```

What is the total number of ordered pairs present in the Cartesian Product **A × B**?

---

### 💡 Explanation

The Cartesian product (`A × B`) contains all possible **ordered pairs** `(a, b)` where:

- `a ∈ A`
- `b ∈ B`

The total number of ordered pairs is:

```
|A × B| = |A| × |B|
```

Since:

```
|A| = 6
|B| = 7
```

Therefore,

```
|A × B| = 6 × 7 = 42
```

---

### 💻 Solution

```
42
```
