## 🚀 5. Basics of Sets and Relations #5

### 📌 Problem

Consider the following data table named **Student**.

| Student Name | Number | Sex |
|--------------|--------|-----|
| Ben | 3412 | M |
| Dan | 1234 | M |
| Nel | 2341 | F |

What is the count of rows returned by the following relational selection?

```
σ(Number < 3000)(Student)
```

---

### 💡 Explanation

The selection operator (`σ`) filters rows that satisfy the given condition.

Here, the condition is:

```
Number < 3000
```

Checking each row:

- Ben → `3412` ❌
- Dan → `1234` ✅
- Nel → `2341` ✅

There are **2** rows that satisfy the condition.

---

### 💻 Solution

```
2
```
