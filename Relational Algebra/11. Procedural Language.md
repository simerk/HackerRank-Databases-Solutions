## 🚀 11. Procedural Language

### 📌 Problem

Which one of the following is a procedural language?

- Domain relational calculus
- Tuple relational calculus
- Relational algebra
- Query language

---

### 💡 Explanation

A **procedural language** specifies **how** to obtain the desired result by defining the sequence of operations to perform.

**Relational Algebra** is a procedural query language because it provides a set of operations (such as selection, projection, join, union, etc.) that describe the steps to retrieve data.

In contrast, **Tuple Relational Calculus** and **Domain Relational Calculus** are **non-procedural (declarative)** languages that specify **what** data is required without describing how to retrieve it.

---

### 💻 Solution

```
Relational algebra
```
