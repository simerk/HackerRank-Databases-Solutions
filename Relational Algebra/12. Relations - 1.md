## 🚀 12. Relations - 1

### 📌 Problem

The _____ operation allows the combining of two relations by merging pairs of tuples, one from each relation, into a single tuple.

- Select
- Union
- Join
- Intersection

---

### 💡 Explanation

The **Join** operation combines tuples from two relations based on a specified condition, producing a single tuple for each matching pair.

It is commonly used to retrieve related data from multiple tables using a common attribute.

For example:

```sql
Student ⨝(Student.Number = TeachingAssistants.ID) TeachingAssistants
```

This merges matching rows from the **Student** and **TeachingAssistants** relations into a single result.

---

### 💻 Solution

```
Join
```
