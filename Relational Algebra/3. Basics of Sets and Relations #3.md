## 🚀 3. Basics of Sets and Relations #3

### 📌 Problem

You are given two sets.

```
Set A = {1,2,3,4,5,6}
Set B = {2,3,4,5,6,7,8}
```

How many elements are present in **A − B**?

---

### 💡 Explanation

The set difference (`A − B`) contains the elements that are present in **A** but **not** in **B**.

```
A − B = {1}
```

There is **1** element in the set.

---

### 💻 Solution

```
1
```
