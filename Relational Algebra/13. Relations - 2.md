## 🚀 13. Relations - 2

### 📌 Problem

The result of which operation contains all pairs of tuples from the two relations, regardless of whether their attribute values match?

- Join
- Intersection
- Cartesian product
- Set difference

---

### 💡 Explanation

The **Cartesian Product** combines **every tuple** from the first relation with **every tuple** from the second relation, without considering whether any attribute values match.

If one relation has `m` tuples and the other has `n` tuples, the Cartesian product contains:

```
m × n
```

tuples.

---

### 💻 Solution

```
Cartesian product
```
