## 🚀 1. Basics of Sets and Relations #1

### 📌 Problem

You are given two sets.

```
Set A = {1,2,3,4,5,6}
Set B = {2,3,4,5,6,7,8}
```

How many elements are present in **A ∪ B**?

---

### 💡 Explanation

The union (`∪`) of two sets contains every distinct element that appears in either set.

```
A ∪ B = {1,2,3,4,5,6,7,8}
```

There are **8** unique elements.

---

### 💻 Solution

```
8
```
