## 🚀 7. Basics of Sets and Relations #7

### 📌 Problem

Consider the following data table named **Student**.

| Student Name | Number | Sex |
|--------------|--------|-----|
| Nina | 3412 | F |
| Mike | 1234 | M |
| Nelson | 2341 | F |

Here is another data table named **Teaching Assistants**.

| Subject | ID |
|---------|----|
| Physics | 3412 |
| Chemistry | 1111 |
| Mathematics | 2341 |

What is the count of rows returned by the following join operation?

```
Student ⊳⊲(Number = ID) Teaching Assistants
```

---

### 💡 Explanation

The join operation returns rows where the condition:

```
Number = ID
```

is satisfied.

Comparing the values:

- Nina → `3412` matches `Physics (3412)` ✅
- Mike → `1234` has no matching ID ❌
- Nelson → `2341` matches `Mathematics (2341)` ✅

Therefore, **2** rows are returned by the join.

---

### 💻 Solution

```
2
```
