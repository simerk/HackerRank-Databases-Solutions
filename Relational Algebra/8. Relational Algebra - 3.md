## 🚀 8. Relational Algebra - 3

### 📌 Problem

Which join condition contains an equality operator?

- Equijoins
- Cartesian
- Natural
- Left

---

### 💡 Explanation

An **Equijoin** is a type of join that uses the equality operator (`=`) to match rows from two tables based on one or more common columns.

For example:

```sql
Student.Number = TeachingAssistants.ID
```

This join returns only the rows where the specified columns have equal values.

---

### 💻 Solution

```
Equijoins
```
