## 🚀 14. Index Architecture Types

### 📌 Problem

How many index architecture type classifications are there in MS SQL Server?

- 1
- 2
- 3
- 4

---

### 💡 Explanation

In **MS SQL Server**, indexes are broadly classified into **two architecture types**:

1. **Clustered Index** – Stores the actual table data in the order of the index key.
2. **Non-Clustered Index** – Stores the index separately from the table data and contains pointers to the corresponding rows.

Therefore, there are **2** index architecture type classifications.

---

### 💻 Solution

```
2
```
