## 🚀 17. Indexes - 4

### 📌 Problem

The correct syntax for creating composite indexes in MS SQL Server is:

- `CREATE INDEX index_name ON table_name(column1), table_name(column2);`
- `CREATE INDEX index_name ON table_name(column1) and table_name(column2);`
- `CREATE INDEX index_name ON table_name(column1, column2);`
- All the above-mentioned syntax are correct.

---

### 💡 Explanation

A **composite index** is an index created on **multiple columns** of the same table.

In MS SQL Server, the correct syntax lists all indexed columns inside a single pair of parentheses, separated by commas:

```sql
CREATE INDEX index_name
ON table_name(column1, column2);
```

The other options are invalid because they either specify columns incorrectly or use the `AND` keyword, which is not valid in the `CREATE INDEX` statement.

---

### 💻 Solution

```sql
CREATE INDEX index_name
ON table_name(column1, column2);
```
