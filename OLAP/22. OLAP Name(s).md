## 🚀 22. OLAP Name(s)

### 📌 Problem

Which of these are alternate names for an OLAP Cube?

The options are:

- (A) Cube
- (B) Multidimensional Cube
- (C) HyperCube
- (D) Both (B) and (C)

---

### 💡 Explanation

An **OLAP Cube** is a multidimensional data structure used for analytical processing. It is commonly referred to as a **Multidimensional Cube** because it organizes data across multiple dimensions such as time, location, and product.

The term **Hypercube** is also used to describe an OLAP cube, especially when the data has more than three dimensions.

Therefore, both **Multidimensional Cube** and **Hypercube** are alternate names for an OLAP Cube.

---

### 💻 Solution

```
Both (B) and (C)
```
