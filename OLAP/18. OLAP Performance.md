## 🚀 18. OLAP Performance

### 📌 Problem

Which of these helps OLAP speed up queries, in terms of performance?

- Dice
- Aggregation

---

### 💡 Explanation

**Aggregation** improves OLAP (Online Analytical Processing) query performance by **precomputing and storing summarized data**. Instead of scanning detailed records for every query, the system can retrieve the required aggregated results directly, significantly reducing query execution time.

Operations like **Dice** are used to filter or select subsets of data but do not inherently improve query performance.

---

### 💻 Solution

```
Aggregation
```
