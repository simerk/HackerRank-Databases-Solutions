## 🚀 21. OLAP Cube Metadata

### 📌 Problem

What is the source of the cube metadata for OLAP?

- Star Schema
- Snowflake Schema
- Standard Database
- Both star and snowflake schema(s)

---

### 💡 Explanation

OLAP cubes are built using metadata that describes facts, dimensions, hierarchies, and relationships. This metadata can be derived from both **Star Schema** and **Snowflake Schema** data warehouse designs.

- **Star Schema** organizes data with a central fact table connected to denormalized dimension tables.
- **Snowflake Schema** is a normalized version of the star schema, where dimension tables are further divided into related tables.

Since OLAP cubes can be created from either schema, both serve as valid sources of cube metadata.

---

### 💻 Solution

```
Both star and snowflake schema(s)
```
