## 🚀 24. OLAP Operation Types

### 📌 Problem

Consider a fact table `DataPoints(D1, D2, D3, x)` and the following three queries:

```sql
Q1:
SELECT D1, D2, D3, SUM(x)
FROM DataPoints
GROUP BY D1, D2, D3;

Q2:
SELECT D1, D2, D3, SUM(x)
FROM DataPoints
GROUP BY D1, D2, D3 WITH CUBE;

Q3:
SELECT D1, D2, D3, SUM(x)
FROM DataPoints
GROUP BY D1, D2, D3 WITH ROLLUP;
```

Suppose attributes **D1**, **D2**, and **D3** have `n1`, `n2`, and `n3` distinct values respectively, and every possible combination appears at least once in the table.

Which of the following tuples `(a, b, c, d, e, f)` correctly represents:

- `n1 = a`
- `n2 = b`
- `n3 = c`
- Result size of **Q1 = d**
- Result size of **Q2 = e**
- Result size of **Q3 = f**

Options:

- `(2, 2, 2, 6, 18, 8)`
- `(2, 2, 2, 8, 64, 15)`
- `(5, 10, 10, 500, 1000, 550)`
- `(4, 7, 3, 84, 160, 117)`

---

### 💡 Explanation

The number of result tuples for each query is:

- **Q1 (GROUP BY):**

```
n1 × n2 × n3
```

- **Q2 (GROUP BY WITH CUBE):**

```
(n1 + 1)(n2 + 1)(n3 + 1)
```

- **Q3 (GROUP BY WITH ROLLUP):**

```
n1n2n3 + n1n2 + n1 + 1
```

Checking the option `(4, 7, 3)`:

```
Q1 = 4 × 7 × 3 = 84
Q2 = (4 + 1)(7 + 1)(3 + 1)
   = 5 × 8 × 4
   = 160
Q3 = (4 × 7 × 3) + (4 × 7) + 4 + 1
   = 84 + 28 + 4 + 1
   = 117
```

All three values match the given option.

---

### 💻 Solution

```
(4, 7, 3, 84, 160, 117)
```
