## 🚀 19. OLAP Operations - 1

### 📌 Problem

This OLAP operation involves computing all of the data relationships for one or more dimensions.

- Dice
- Slice
- Pivot
- Roll-up

---

### 💡 Explanation

The **Roll-up** operation aggregates data by climbing up a hierarchy or reducing the level of detail across one or more dimensions. It computes summarized values and relationships at higher levels, making it easier to analyze data at different levels of granularity.

For example, sales data can be rolled up from:

```
City → State → Country
```

to obtain summarized results at the state or country level.

---

### 💻 Solution

```
Roll-up
```
